# CheckGate · 三平台发布前合规自检

抖音 / 视频号 / 小红书——**同一句话，三个平台的规则判定并不一样。**

CheckGate 是一个纯静态的发布前自检工具：粘贴文案 → 选平台 → 逐字告诉你哪些表述在规则库里、依据哪条规则、第几个字、改成什么。**全部在浏览器本地完成，文案不上传。**

在线使用：https://checkgate.app.workbuddy.host/?sharecode=EK2MBAGVWH

---

## 它做什么

- **三平台规则库检索**：374 条（2026-10-21 版），每条标注依据的法规条款与平台规范章节号，可跳转官方来源自行核对
- **命中定位**：精确到第几个字的哪个词
- **改写建议**：每条给正向改写方向（删除前缀 / 改为具体表述 / 补充来源与日期），不是同义替换词库
- **变体识别**：繁体、全角、数字替换、符号分隔、空格插入——位置索引精确到 Unicode 码点
- **AI 语义补充（可选）**：用户自带模型 API Key（百炼 / OpenAI 兼容），检测同样在本地完成

## 它不做什么

- **不断言「发了会怎样」**——判定权在平台。工具只告诉你规则库收录了什么
- **不教怎么绕过审核**——这个项目只讲规则为什么这样定。变体识别能力用于自检，不用于规避
- **不承诺改完就过**——平台审核包含未公开维度

## 规则库现状（2026-10-21 版）

| 项 | 值 |
|---|---|
| 总条数 | 374 |
| 三平台通用 | 103 |
| 仅视频号 / 仅小红书 / 仅抖音 | 113 / 67 / 28 |
| 溯源状态 | verified 274 · partial 100 |

> `partial` = 官方页面已改版、或细分口径以后续公告/细则为准——如实标注，不混同为「已核实」。

规则来源包括《广告法》《价格法》《人工智能生成合成内容标识办法》及各平台运营规范 / 社区公约。收录范围与条款号以 `rules.json` 为准。

## 自己跑

纯静态，零依赖：

```bash
python3 -m http.server 8000   # 或 npx serve .
# 浏览器打开 http://localhost:8000
```

也可以直接用浏览器打开 `index.html`。

## 自己验

规则库完整性与检测引擎都可独立复算：

```bash
node verify-rules.js   # 规则库一致性：必填字段 / 合规红线 / 交叉一致性 / 收录分布 / 溯源 / 重复 / 语义指纹
node verify.js         # 引擎独立验收（26 项）
node test.js           # 引擎自测（90 项）
```

语义指纹 `f4f1bc72`（词条 / 等级 / 平台 / 依据的哈希）——规则库任何改动都会变，变了就重算再引用。

## 规则库怎么维护

- 9 个抓取源：各平台规则中心、运营规范、社区公约、法律法规库
- 每周巡检：抓取 → 解析 → diff → 人工抽检
- 三层兜底：溯源自检（链接可达性）/ 抽样回溯（随机验规则是否仍存在）/ 变更告警
- 溯源分级如实：`verified` 与 `partial` 分开标注
